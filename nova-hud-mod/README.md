# Nova HUD

Nova HUD is a small client-side Fabric mod bundled with Nova Client. It displays FPS, block coordinates, facing direction, and the current dimension in a compact overlay.

## Build

Use Java 25 and run `gradlew.bat build`. The compiled jar is written to `build/libs/`.

Nova HUD targets Minecraft 26.3 and Fabric Loader. The project is based on Fabric's CC0 example template.
